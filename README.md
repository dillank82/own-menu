# Own Menu

A mobile menu app with personalized recipes. Instead of
thinking what to cook each time, you choose from already mastered
recipes — by section, by swiping, or by random selection.

## Idea

- Sections: breakfast, first course, second course, dessert
- Each section contains a list of added recipes (ingredients separated from cooking steps)
- Outdated recipes can be archived without deleting
- You can swipe the list or select a random recipe

## Stack

Expo / React Native, TypeScript
